# Задача 4. Поиск слова в файле

## Описание
Программа ищет заданное пользователем слово в текстовом файле `article.txt` и подсчитывает количество строк, в которых оно встречается.

Поиск выполняется без учёта регистра: например, `Python`, `PYTHON` и `python` считаются одинаковыми.

## Подготовка
1. Создайте файл `article.txt` в папке с программой.
2. **Вставьте в файл `article.txt` любой текст**, который хотите использовать для поиска. Текст может состоять из нескольких строк.
3. Сохраните файл.

## Как запустить
1. Запустите Python-программу.
2. Введите слово, которое хотите найти.
3. Программа выведет количество строк, содержащих это слово.

## Пример

Содержимое файла `article.txt`:

```text
Python — популярный язык программирования.
Мне нравится изучать Python.
Программирование помогает решать задачи.
PYTHON используется для разработки.
```

Ввод пользователя:

```text
python
```

Результат:

```text
Количество строк: 3
```

## Важно
- Файл `article.txt` должен находиться в той же папке, что и программа.
- Перед запуском необходимо вставить в `article.txt` свой текст.
- Поиск не зависит от регистра букв.
- Если слово встречается в одной строке несколько раз, эта строка учитывается только один раз.
